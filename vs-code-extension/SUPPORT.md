# Support

For help with UnitySerializedShield, please open an issue in the project repository if one is available.

When reporting a problem, include:

- Your Visual Studio Code version.
- Your Unity version.
- A small C# script that shows the rename pattern.
- What you expected UnitySerializedShield to insert.
- What UnitySerializedShield inserted instead.

Do not include private project files unless you have removed sensitive code and data.
